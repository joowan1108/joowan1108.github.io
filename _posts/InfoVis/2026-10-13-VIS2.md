# Definition and Justification

**Data**: raw materials without insights

**Information**: Data을 analyze 한 다음에 얻는 meaningful한 정보. Data으로부터 insight을 뽑아낸 결과


## InfoVis

Important Concepts
- **Abstract data**
	- Scientific visualization은 이미 공식적인 representation 방법이 존재하지만 abstract data는 그렇지 않음
- **Humans 중요**
	- 많은 문제들이 ill specified하다. 즉, 문제 및 목표가 불확실하기 때문에 사람이 개입하여 어떤 데이터로 어떤 문제를 해결할 것인가를 알아내야 한다
- **Computer 중요**
	-  사람이 다 할 순 없으므로
	- Response time, interactivity, errors, scalability, generalizability
- **Visual representation 중요**
	- Visiual representation은 accurate하고 **preattentive processing**이 가능함
	- Visual representation은 external memory, external representation의 역할을 함.
- **상호작용 중요**
	- 하나의 view에 모든 차원을 담을 수 없음
	- user가 보고싶은 것을 상호작용을 통해 볼 수 있게 해야 함


## Vis Idiom

특정 데이터를 표현하기 위해 어떤 visual representation을 고려할 것인가를 선택하는 방법
ex) Bivariate data을 위한 vis idiom은 scatter plot

이때 task, effectiveness, validation을 해야 한다.

Vis system을 구축할 때 고려해야 하는 3가지는 다음과 같다

- **Computational capacity**
	- Scalability와 responsiveness을 위해
- **Human perceptual and cognitive capacity**
	- 사람의 memory와 attention은 유한함
- **Display capacity**
	- Pixel 수는 유한함

Vis system에서 중요한 것

- **Data abstraction**
	- What data does the user see?
- **Task abstraction**
	- Why does the user use the system?
- **Idiom abstraction**
	- How are the visual encoding and interaction idioms constructed?

> **Information density**: 사용 안 된 공간 대비 표현된 정보량
